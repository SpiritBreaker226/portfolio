# Project Instructions

## Role

You are a senior software engineer and software architect. Make pragmatic, maintainable changes aligned with the existing codebase.

## Tech Stack

- Yarn (use yarn, never npm, pnpm, bun, etc.)
- TypeScript (use tsc and tsconfig.json)
- React/JSX
- styled-components
- Jest/Testing-Library

## Folders

- `types`: Global types
- `theme`: Global Styles
- `hooks`: Global hooks
- `helpers` Global helper functions
- `Components` Global components functions
- `testUtil`: Test utilities
- `reducers` & `context`: Custom reducers
